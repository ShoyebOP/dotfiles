# Plan 01-03: Bash guard for sh invocation (G-01-12)

> **As a** user who habitually types `sh setup.sh`, **I want to** see a clear "must be run with Bash" message **so that** I know to use `bash setup.sh` instead of a cryptic `Illegal option -o pipefail`.

<objective>
Fix UAT gap G-01-12: `sh setup.sh` currently crashes at line 2 `set: Illegal option -o pipefail` with no guidance. Insert a POSIX-safe Bash detection guard before any Bash-only strict mode so the script fails fast with friendly instructions, preserving all existing `bash setup.sh` behavior.

Purpose: Closing the sh-vs-bash invocation trap without regressing the verified bash path.
Output: `sh setup.sh` prints guidance and exits 1; `bash setup.sh --help` and `./setup.sh --help` still exit 0 with usage; `bash -n setup.sh` remains clean.
</objective>
