# Plan 01-02: Checklist ladder, stow orchestration, quarantine, post-verify, staged delete

> **As a** user with a fresh clone on Arch, Debian-family, or Termux, **I want to** pick my mode, shell, and exact package set from a checklist **so that** one run links precisely what I chose, previews everything first, never destroys my existing files, and proves the links correct.

<objective>
Wire the 01-01 spine into the complete deployment flow: mode → shell → 7-package checklist ladder (INST-01/INST-04) gated before any write, full `--dry-run` preview of installs plus stow simulation (INST-02), collision quarantine with manifest (D-13/D-14), explicit-dir stow deploy (STOW-01, idempotent restow per DEPS-03), folding-aware strict post-verify (D-16), the Phase 1 keyd selection decision, staged deletion of the legacy setup scripts with atomic doc/comment repair (D-02/D-03/D-04), and the outside-repo-root abort.

Purpose: This turns the resolver into the shippable Phase 1 installer — the first plan a user can actually deploy with.
Output: `bash setup.sh` deploys the chosen set into a (sandbox or real) HOME correctly, provably, and reversibly.
</objective>
